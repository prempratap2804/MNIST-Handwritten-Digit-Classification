# MNIST-Handwritten-Digit-Classification
A Machine Learning project for classifying handwritten digits (0–9) using the MNIST dataset.
# MNIST Handwritten Digit Classification

## Overview
This project focuses on handwritten digit classification using Machine Learning. The goal is to classify images of handwritten digits from 0 to 9.

## Objective
Build a classification model capable of recognizing handwritten digits from image data.

## Dataset
The MNIST dataset consists of handwritten digit images representing numbers from 0 to 9.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow
- Load the dataset
- Explore and understand the data
- Preprocess the images
- Train a classification model
- Evaluate model performance
- Predict handwritten digits

## Project File
- `mnist-classification.ipynb` — Jupyter Notebook containing the implementation of the handwritten digit classification project.

## Applications
- Handwritten digit recognition
- Automated number recognition
- Image classification

## Purpose
This project was developed to practice Machine Learning classification techniques and understand how models can recognize patterns in image data.
